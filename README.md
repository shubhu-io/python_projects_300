# 300 Python Projects

This repository contains a collection of 300 Python projects categorized by difficulty:
- `01_beginner/`
- `02_intermediate/`
- `03_advanced/`

Each project is contained within its own folder and includes a `README.md` explaining its purpose, the core Python concepts used, and instructions on how to run it.

## How to use
Navigate to any of the specific project directories and follow the instructions in the project's `README.md`.

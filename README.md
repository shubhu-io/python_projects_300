## 📂 Repository Structure

The 300 projects are divided into three distinct difficulty tiers:

### 🟢 `01_beginner/` (Projects 1 - 100)
Perfect for those just starting out with Python. These projects focus on core programming concepts.
- **Concepts Covered:** Variables, Loops, Conditionals, Functions, Basic I/O, and simple logic.
- **Examples:** Calculators, Number Guessing Games, Text Analyzers, and CLI utilities.

### 🟡 `02_intermediate/` (Projects 101 - 200)
For developers ready to step up their game. These projects introduce more complex data structures, external libraries, and file manipulation.
- **Concepts Covered:** OOP (Object-Oriented Programming), APIs, Web Scraping, File Handling (CSV/JSON), and simple GUIs.
- **Examples:** Weather Dashboards, Markdown to HTML converters, Web Scrapers, and Budget Trackers.

### 🔴 `03_advanced/` (Projects 201 - 300)
Complex, architecture-heavy projects meant to challenge experienced developers.
- **Concepts Covered:** Concurrency/Asyncio, Machine Learning, Networking/Sockets, Advanced Algorithms, and System Architecture.
- **Examples:** Custom Interpreters, Blockchain Nodes, Mini Neural Networks, and Distributed Systems.

## 🛠️ How to Use This Repository

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shubhu-io/python_projects_300.git
   cd python_projects_300
   ```
2. **Navigate to a project:**
   Pick a difficulty tier and navigate to a project folder that interests you.
   ```bash
   cd 01_beginner/001_hello_world_plus
   ```
3. **Read the Docs & Run the Code:**
   Open the `README.md` in that folder to understand the project. Then, run the Python file:
   ```bash
   python 001_hello_world_plus.py
   ```
